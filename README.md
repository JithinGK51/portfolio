A premium, high-performance developer portfolio featuring smooth animations, interactive 3D elements, and a clean, modern aesthetic. Built with React, TypeScript, and Framer Motion.

## ✨ Key Features

- **🏆 interactive Achievements Timeline**: A visually engaging vertical timeline featuring scroll-triggered animations for professional milestones.
- **💼 Dynamic Experience Section**: Detailed internship records (Vidyavahini Degree College, ImpaqX) with premium glow effects and international collaboration highlights.
- **📄 Robust Resume System**: Highly interactive resume button with motion feedback, featuring both "Open on Site" (Modal Viewer) and "Download PDF" functionality.
- **📊 GitHub Showcase**: Real-time GitHub activity integration, displaying top repositories and language statistics.
- **🌗 Responsive Design**: Fully optimized for mobile, tablet, and desktop with a focus on premium interactivity.
- **🎨 Modern UI**: Custom animations, glassmorphism, and a curated color palette for a high-end feel.

## 🛠️ Technology Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [ScrollReveal](https://scrollrevealjs.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Data Fetching**: [TanStack Query](https://tanstack.com/query/latest)

## 📁 Project Structure

```text
src/
  components/
    animations/   # Reusable animation wrappers (ScrollReveal, TypeWriter)
    sections/     # Portfolio sections (Hero, About, Experience, Projects, etc.)
    ui/           # Base UI components (Buttons, Modals, Cards)
  hooks/          # Custom hooks (useGithubData)
  pages/          # Main application screens
  assets/         # Static assets (Resume PDF, images)
```

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18 or later)
- **npm** or **bun**

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/JithinGK51/portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

### Production Build

To create an optimized production build:
```bash
npm run build
```
The output will be generated in the `dist/` directory.

## 🌐 Deployment

This project is automatically deployed to [www.jithin.crafzio.in](https://www.jithin.crafzio.in) via **Netlify** whenever changes are pushed to the `portfolio1` branch.
