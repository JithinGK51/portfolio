# Jithin GK | Developer Portfolio

Full Stack Developer — crafting digital experiences with clean code and modern design.

## Project Structure

```text
src/
  components/     # Reusable UI components
  pages/          # Main application screens
  hooks/          # Custom React hooks
  lib/            # Utility functions and shared instances
  App.tsx         # Main application entry point
```

## Technologies Used

- **Vite**: Modern frontend build tool
- **React**: Library for building user interfaces
- **Tailwind CSS**: Utility-first CSS framework
- **Lucide React**: Icon library
- **Framer Motion**: Animation library

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/JithinGK51/portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:8080`.

### Building for Production

To create an optimized production build:
```bash
npm run build
```

The output will be in the `dist/` directory.
